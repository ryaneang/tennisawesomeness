# Baseline Swipe

A responsive arcade tennis game controlled with mouse or touch gestures. Swipe upward for topspin, downward for slice, and left or right to place the ball.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite. The game is designed for desktop and landscape mobile screens.

## Controls

- Tap or click to toss the ball on your serve.
- Swipe near the top of the toss to serve.
- Swipe upward for topspin or downward for slice.
- Swipe longer and faster for more pace and depth.
- Press Escape to pause.

The first player to 11 points wins. The server changes after every two points.
